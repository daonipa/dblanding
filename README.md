# 프리미엄 3대 암 치료비 플랜 랜딩페이지

고급스러운 디자인과 반응형 레이아웃을 갖춘 보험 상담 랜딩페이지입니다.

## 🌟 주요 특징

- **Premium Design**: Deep Navy & Gold 컬러 조합으로 신뢰감과 고급스러움 강조
- **Responsive Layout**: PC, 태블릿, 모바일 등 모든 기기에서 최적화된 화면 제공
- **Interactive UI**:
  - 스크롤 시 부드러운 등장 애니메이션 (Scroll Reveal)
  - 마이크로 인터랙션 (버튼, 카드 호버 효과)
  - 모바일 하단 고정 CTA 버튼
  - 플로팅 라벨 입력 폼

## 🛠 기술 스택

- **HTML5**: 시멘틱 마크업
- **CSS3**: Flexbox/Grid, CSS Variables, Animations
- **JavaScript**: Vanilla JS (No dependencies)
- **Fonts**: Pretendard (본문), FontAwesome (아이콘)

## 📁 프로젝트 구조

```
dblanding/
├── css/
│   └── style.css      # 메인 스타일시트
├── js/
│   └── script.js      # 인터랙션 스크립트
├── index.html         # 메인 페이지
└── README.md          # 프로젝트 설명
```

## 🚀 실행 방법

1. `index.html` 파일을 브라우저에서 실행하거나
2. VS Code의 'Live Server' 확장을 통해 로컬 서버에서 확인
